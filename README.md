# Amazon Clone

A responsive clone of the Amazon homepage built using HTML and CSS. This project focuses on replicating the layout and design of Amazon across different screen sizes.

## Features

* **Responsive Design:** Works on desktop, tablet, and mobile screens.
* **Navigation Bar:** Includes the logo, search bar, and cart icon.
* **Product Grid:** Displays product cards in a clean, organized layout.
* **Footer:** Contains the classic multi-tier Amazon footer.

## Tech Stack

* HTML5
* CSS3 (Flexbox, Grid, and Media Queries)

## How to Run Locally

1. Download or clone the project files to your computer.
2. Navigate to the project folder.
3. Open the `index.html` file in any web browser.
